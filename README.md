# Cline CLI

A tiny Node.js command-line interface named `cline` for the workspace.

## Install locally

```sh
npm install
```

## Usage

```sh
node cline.js --help
node cline.js --version
node cline.js status
```

You can also run the executable directly after making it executable:

```sh
chmod +x cline.js
./cline.js --help
```

## Commands

- `status` prints `Cline CLI is ready`
- `--help` prints usage and options
- `--version` prints the package version
